# Swarm_Learning_A14
Swarm_learning_A14 is a reserach based project which is being done under guidance of B. Lalitha Rajeswari Madam, Assistant Professor, VVITU, Namburu. 
This Project is not about building a swarm learning atmosphere but it is about building a *Contribution-Aware Trust Mechanism for Poisoning Attack Detection in Swarm Learning.*
This Project includes different trust mechanisims to differentiate the difference between *Honest NON-IID models* and *Malicious participants.*
